# 自驾游开销计算器

> 出行前估一估，路上不超支。

一款基于 **uni-app (Vue 3)** 开发的自驾游费用估算跨端应用。用户填入行程、车型能耗、住宿餐饮以及额外预算后，即可一键生成费用估算报告，并通过玫瑰图查看各项开销占比，支持生成分享海报与报告链接分享。

[English](./README.en.md) | 中文

## 功能特性

### 行程录入（首页）

- **基础行程**：行驶里程（去程）、是否往返（往返按去程里程 × 2 计算总里程）、是否走高速。
- **车辆类型与能耗**：支持油车 / 电车 / 混动车三种车型切换。
  - 油车：百公里油耗、当前油价。
  - 电车：百公里电耗、平均电价。
  - 混动车：百公里电耗、平均电价、亏电油耗、当前油价，并通过滑杆调节**纯电比例**，按比例加权计算能耗成本。
- **行程与人数**：行程周期（天）、出行人数。
- **住宿与餐饮**：日均住宿费、人日均餐费。
- **额外预算**：可自由增删项目，支持标记项目是否按**人均**计算。

### 费用估算报告

- **顶部总览**：总花费、每公里花费、人均花费、总里程。
- **费用占比**：玫瑰图（uCharts）展示各分类占比，配合颜色图例。
- **费用明细**：各分类金额、占比及占比进度条。
- **额外支出明细**：逐项展示金额与「人均 / 总计」标记。
- **行程小结**：车型 · 天数 · 人数 · 总里程。

### 分享能力

- **图片分享**：使用 Canvas 2D 离屏绘制分享海报，可保存到相册。
- **报告分享**（小程序端）：分享携带压缩后的报告数据，好友打开即可还原同一份报告。

### 体验细节

- **深色模式**：跟随系统 `prefers-color-scheme` 自动切换，导航栏配色由 `theme.json` 统一管理。
- **金额为 0 的分类自动隐藏**：例如未走高速时不展示高速费。
- **人数为 1 时**：人均花费卡片自动隐藏，总花费卡片占满整行。

## 快速开始

本项目为 HBuilderX 工程（未使用 CLI），推荐使用 HBuilderX 打开运行。

1. 使用 [HBuilderX](https://www.dcloud.io/hbuilderx.html) 打开项目根目录。
2. 选择菜单 **运行 → 运行到浏览器 / 运行到小程序模拟器**（如微信开发者工具）。
3. 若运行到微信小程序，请在 `manifest.json` 的 `mp-weixin.appid` 中替换为你自己的 AppID。

> 首次在微信开发者工具中运行时，需先在工具中开启「服务端口」以便 HBuilderX 调用。

## 计算规则

| 项目 | 计算公式 |
| --- | --- |
| 总里程 | `去程里程 × (是否往返 ? 2 : 1)` |
| 行驶成本（油车） | `总里程 × 百公里油耗 ÷ 100 × 油价` |
| 行驶成本（电车） | `总里程 × 百公里电耗 ÷ 100 × 电价` |
| 行驶成本（混动） | `总里程 × 电耗 ÷ 100 × 电价 × 纯电比例 + 总里程 × 亏电油耗 ÷ 100 × 油价 × (1 − 纯电比例)` |
| 高速费 | `是否走高速 ? 总里程 × 0.5 元/公里 : 0` |
| 住宿费 | `日均住宿费 × 天数` |
| 餐饮费 | `人日均餐费 × 人数 × 天数` |
| 额外支出 | `Σ (项目是否人均 ? 金额 × 人数 : 金额)` |
| 总花费 | 以上五类费用之和 |
| 人均花费 | `总花费 ÷ 人数` |
| 每公里花费 | `行驶成本 ÷ 总里程` |

### 默认值

| 参数 | 默认值 |
| --- | --- |
| 里程 / 天数 / 人数 | 500 公里 / 5 天 / 2 人 |
| 住宿 / 餐饮 | 300 元/天 · 100 元/人/天 |
| 油车 | 8 L/100km · 8 元/L |
| 电车 | 15 kWh/100km · 1.5 元/度 |
| 混动车 | 15 kWh/100km · 1.5 元/度 · 5 L/100km · 8 元/L · 纯电比例 50% |
| 额外预算 | 停车费 100 元（总计）、景点门票 100 元（人均） |
